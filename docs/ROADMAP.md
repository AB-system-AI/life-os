# Roadmap

1. Replace starter data with a deliberate first-run setup; give the user control of their profile and make sample content explicitly optional/removable.
2. Extract shared domain types and validation; introduce persistence repositories, versioned migrations, IndexedDB, backup, and restore.
3. Complete tasks, calendar, habits, and reminders with real records and tests.
4. Implement education, career, and project models with configurable academic grading rules.
5. Implement decimal-safe finance, journal, spiritual-life, wellness, and goals modules.
6. Add global search, import/export, preferences, accessible RTL/LTR review, and honest dashboard analytics.
7. Add offline web shell and test offline behavior; establish production headers and dependency review.
8. Add Expo SQLite adapter/mobile UI and Tauri SQLite adapter/Windows shell, then build and verify each platform.
9. Add unit, integration, browser end-to-end, accessibility, and performance coverage; prepare platform release artifacts and signing guidance.
